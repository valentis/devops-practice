# OpenAPI Specification Notes

## Auto-generation
The spec is auto-generated by FastAPI from route decorators and Pydantic models.
Access at: `GET /openapi.json`

## Adding descriptions
Use docstrings on route functions:
```python
@app.get("/users/{id}")
def get_user(id: int):
    """Retrieve a user by ID."""
    ...
```

## Versioning
Prefix all v2 routes with `/v2/` and set `openapi_version="3.1.0"` in `FastAPI()`.
